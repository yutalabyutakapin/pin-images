# pin-images

Pinterest の一括アップロードで使う画像の置き場所です。

Pinterest は公開URLから画像を取りに行く仕組みなので、そのために公開しています。
取り込まれた画像は Pinterest 側に複製されるため、ここのURLはピンを見た人には表示されません。
